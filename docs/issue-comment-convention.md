# 이슈 댓글 컨벤션 — [AI feature 요약]

feature별 GitHub 이슈에 "어떻게 구현/수정했는지"를 AI(Claude Code)가 코드·커밋을 조사해 댓글로 남긴다.
이슈 본문은 요구사항, 댓글은 구현 기록이라는 역할 분리.

## 형식

```md
## [AI feature 요약]

**상태:** 구현 완료 | 부분 구현 | 미구현 | 수정 완료   (버그는 **원인:** / **수정:** 한 줄씩)

### 구현 방식 (또는 원인 / 수정 방식)
- 핵심만. 배경 설명 늘어놓지 않기

### 구조            ← 흐름이 있을 때만. 표 / ASCII 다이어그램
### 핵심 코드        ← 1~3개, 파일 경로를 위에 적고 필요한 줄만 (`...`로 생략)
관련 커밋: `해시` 메시지
### 남은 작업 / 참고  ← 실제로 남은 게 있을 때만
```

## 규칙

- 제목 `## [AI feature 요약]`을 항상 맨 위에. 사람이 쓴 댓글과 구분하기 위함.
- 상태는 정직하게. 이슈가 요구한 것 중 안 된 부분은 "미구현"으로 명시 (예: #33 서버 요청 로깅).
- 근거는 코드와 `git log -p` / `git show <hash>`. 이슈 본문이 비어 있으면 커밋 메시지·코드 주석의 증상 서술을 근거로 삼고, 확정 못 한 건 "추정"으로 표기 (예: #43).
- 한국어, 담백하게. 인사말·수식어 없음.

## 작업 절차

1. `gh issue view <n> --json title,body,comments`로 이슈 의도 파악
2. 관련 커밋 찾기: `git log --oneline | grep`, `git show <hash> --stat`, 현재 코드 확인
3. 초안을 파일로 작성 → `gh issue comment <n> --body-file <file>`
4. 수정은 `gh api -X PATCH repos/RunnserJeju/runnerJeju/issues/comments/<id> -F body=@<file>`
   (댓글 id는 등록 시 반환된 URL의 `issuecomment-<id>`)
